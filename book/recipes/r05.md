@recipe r05

The smallest program that needs a real dependency graph. A spreadsheet has
cells that refer to other cells, which means it can have cycles, which means
it needs an evaluator that detects them and an interface that reports them
without losing the user's text.

@demo r05-spreadsheet

## What stays local, what crosses

| Normally local | Worth crossing |
|---|---|
| Move, select ranges, type | "What is driving the West number down?" |
| Evaluate formulas | "Add a column for margin" |
| Copy a range | "Check these prices against the catalogue" |
| Undo | |

Formula evaluation is emphatically local. A grid that asked a model to compute
`=SUM(B2:B5)` would be slower, more expensive and occasionally wrong.

## The evaluator

Numbers, cell references, arithmetic and `SUM` over a range, in about twenty
lines, with a `seen` set threaded through the recursion to catch cycles.

<!-- listing: illustrative -->
```js
function evaluate(ref, seen = new Set()) {
  const raw = cells.get(ref) ?? "";
  if (!String(raw).startsWith("=")) return Number(raw) || (raw === "" ? 0 : NaN);
  if (seen.has(ref)) throw new Error(`Circular reference at ${ref}`);
  seen.add(ref);
  /* ... expand SUM, then references, then evaluate ... */
}
```

The guard is a whitelist regular expression before the expression is
evaluated, so a cell containing arbitrary text cannot become arbitrary code.
That is not paranoia about the user; the cells can be populated from a tool
result, which came from a server.

## Errors that keep the input

A cycle shows `#CYCLE` in the grid and leaves the raw text in the cell and in
the formula bar, with a banner explaining what happened. Clearing the user's
input because it was invalid is the failure mode that makes people distrust a
grid.

## Range selection and the clipboard

Anchor and head, shift to extend, arrows to move, and the selected range is
highlighted rather than just the active cell. Copy produces tab-separated
values with newlines, which is what every other spreadsheet reads.

Chapter 10 has the general rule: CSV for a file, TSV for the clipboard. A
range copied as prose is a range nobody can paste.

## Try this

**Type `=B2*C2*2` into D2.** The column recomputes, and so does the total in
D6, because evaluation is recursive rather than cached.

**Type `=D2` into B2.** The grid shows `#CYCLE`, the cell keeps your text, and
the banner explains. Nothing is cleared.

**Shift with the arrow keys, then press Copy.** The clipboard holds
tab-separated values, which is what a spreadsheet expects and what prose is
not.

## What it needs from the host

| Level | Needs | Without it |
|---|---|---|
| 1 | Render, resize, theme | Nothing works |
| 2 | `clipboard.write` | Falls back to `execCommand`; still works |
| 2 | `clipboard.read` | Paste is unavailable; this is a gap, not a host choice |
| 4 | `tool.invoke` | No sheet to load |

## What happens when things go wrong

**Paste.** There is no clipboard read anywhere, so importing a range from
another spreadsheet means pasting into a focused cell and letting the browser
deliver it, which works for one cell and not for a range. Chapter 10 has the
gap; this recipe is where it costs the most.

**A formula referring to an empty cell.** Evaluates to zero rather than to an
error, which is what every spreadsheet does and what users expect.

## Keyboard and screen reader

Every cell is an `<input>` with an `aria-label` carrying its reference, so a
screen reader user hears "B4, 1601" rather than "edit text". Arrows move,
shift extends, and the formula bar shows the raw content of the head cell.
Changes announce the cell and its new value. The grid is not virtualised,
which is a deliberate limit: six rows by four columns, because a virtualised
grid with correct accessibility is a much larger piece of work than this
recipe is trying to demonstrate.

## Conformance checks

1. `load_sheet` populates twenty cells including four formulas.
2. Column D shows computed products, not formula text.
3. Editing B2 changes D2 and B6 in the same frame.
4. Entering a self-reference shows `#CYCLE` and keeps the typed text.
5. Shift with arrows extends the highlighted range.
6. Copy places tab-separated text on the clipboard.
7. Undo restores the previous cell content.
